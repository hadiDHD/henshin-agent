# Learned Knowledge

This directory contains experiential knowledge learned by the Henshin Agent during its operation.

## Structure
- `00_LEARNED_INDEX.md`: A searchable index of all learned entries.
- `entries/`: Individual markdown files for each learned rule (on accept) or anti-pattern (on reject).

## Usage for Agents
1. Always scan `00_LEARNED_INDEX.md` at the start of a session.
2. Read relevant entries to avoid repeating mistakes or to reuse successful patterns.
3. Anti-patterns are prefixed with `reject-` and contain descriptions of why a rule was rejected by the user.
